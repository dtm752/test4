# АйДа! Белорецк — сайт

Статический сайт без сборки и внешних зависимостей: чистый HTML, CSS и JavaScript.
Приём заявок — **только по телефону**. Форм, CRM и вебхуков нет.

**7 страниц · 3,6 МБ · шрифты и изображения локальные · ничего не грузится с чужих серверов**

---

## Как опубликовать на GitHub Pages

1. Создайте репозиторий на GitHub (можно публичный — Pages работает бесплатно).
2. Загрузите **содержимое этой папки** в корень репозитория. Важно: `index.html` должен лежать в корне, а не внутри вложенной папки.
3. Откройте **Settings → Pages**.
4. В разделе *Build and deployment* выберите **Source: Deploy from a branch**, ветку **main**, папку **/ (root)**.
5. Сохраните. Через 1–3 минуты сайт появится по адресу `https://ИМЯ.github.io/РЕПОЗИТОРИЙ/`.

Всё работает по относительным путям, поэтому сайт открывается и в подпапке GitHub Pages, и на своём домене.

### Свой домен

В **Settings → Pages → Custom domain** впишите домен, добавьте у регистратора CNAME на `ИМЯ.github.io`, включите **Enforce HTTPS**. После подключения домена замените `https://aidabeloretsk.ru/` на фактический адрес в файлах `sitemap.xml`, `robots.txt` и мета-тегах `canonical` / `og:url`.

### Как обновлять

Загрузите изменённые файлы в тот же репозиторий — Pages пересоберёт сайт автоматически. Ничего компилировать не нужно.

## Что заменить перед запуском

Все заглушки помечены и легко находятся поиском по проекту:

- **Телефон** — `+7 (XXX) XXX-XX-XX` и `tel:+70000000000` во всех файлах.
- **ИП и ИНН** в футере — `[ФИО]`, `[000000000000]`.
- **Соцсети** — ссылки `ВКонтакте` и `Telegram` ведут на `#`.
- **Юридические документы** — «Политика обработки данных», «Правила бронирования», «Оферта» ведут на `#`.
- **Фотографии** — часть кадров художественно обработана, для постоянной публикации лучше заменить на реальную съёмку.
- **Аттестация и лицензия гида** — в текстах заявлены; проверьте, что документы действуют, и укажите номер записи в реестре инструкторов-проводников.
- **Страховка** — заявлена как включённая в стоимость; подтвердите условиями.
- **Домен** — `aidabeloretsk.ru` в мета-тегах, `sitemap.xml` и `robots.txt`.

## Локальный просмотр

```bash
cd site
python3 -m http.server 8080
```

Открыть `http://localhost:8080/`. Запускать через сервер, а не двойным щелчком по файлу: иначе некоторые браузеры не загрузят шрифты.

## Технические характеристики

- **Адаптивность** — проверено на 10 разрешениях: от 360×800 (Galaxy S20) до 1920×1080. Горизонтальной прокрутки нет нигде. Тест автоматический, 7 страниц × 10 устройств, 70 проверок: горизонтальная прокрутка, битые изображения, элементы за краем экрана, текст мельче 11 px, тач-цели меньше 32 px.
- **Доступность** — один `h1` на страницу, иерархия заголовков без пропусков, у всех изображений `alt`, тач-цели от 32 px, контраст основного текста по WCAG AA.
- **SEO** — уникальные `title` и `description`, `canonical`, Open Graph, микроразметка Schema.org (`Product`, `TouristTrip`, `FAQPage`, `BreadcrumbList`), `sitemap.xml`, `robots.txt`, `hreflang` для пары RU/EN.
- **Производительность** — без внешних CDN, шрифты и картинки локальные, изображения с `width`/`height` (нет сдвига вёрстки), `loading="lazy"` для всего ниже первого экрана.

## Как поменять даты и цены

Все даты выездов и цены лежат в одном месте — в начале `assets/app.js`:

```js
var PRICES = { quad: {...}, mg: {...}, hike: {...} };
var DEPARTURES = { quad: [...], mg: [...], hike: [...] };
```

- `quad` — квадро из Белорецка (3 650 / 3 000 ₽);
- `mg` — «Магнитогорские субботы» (4 500 / 4 000 ₽, только субботы);
- `hike`, `aigir`, `yandyk` — пешие маршруты (от 1 500 ₽).

`seats` — вместимость **одной** машины (6 мест), `machines` — сколько машин ставите на дату.
Две машины = 12 мест. Лента на главной и шторка брони собираются из этих данных автоматически,
отдельно править HTML не нужно.

Анонс-полоса сверху — это блок `<a class="promo-bar">` в начале каждой страницы, правится в 7 файлах.
